## Earlier versions

MolModa was first described in Kochnev Y, Ahmed M, Maldonado AM, Durrant JD
(2024) MolModa: accessible and secure molecular docking in a web browser.
*Nucleic Acids Res* 52:W498-W506. Contributors to that version whose work
persists in the current codebase are credited above.

MolModa incorporates code from earlier Durrant lab projects, including Webina
and FPocketWeb, whose contributors are credited in those projects'
repositories.
